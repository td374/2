## 1. 核心科学问题（一句话）

> **RUL 预测模型所获得的「预测增益」，在多大程度上真正来自输入特征，
> 而不是来自标签结构、常数基线或测试对象的选取？这种增益在工况变化后是否仍然存在？**

拆成两个层次（V2.0 §1.2）：

| 层次 | 内容 | 对应章节 |
|---|---|---|
| 第一层 **预测性能的形成** | 标签结构 → 目标分布 → 输入特征 → 最终误差 | Ch5 |
| 第二层 **预测能力的迁移** | 源工况上的增益**不能**自动推断到未见工况 | Ch6 |

**这不是一个「谁更好」的问题**，而是一个「增益从哪来、能走多远」的问题。

## 2. 四个研究问题 RQ1–RQ4（逐层推进，不可平行堆放）

| 编号 | 研究问题 | 核心检验 | 计算对象 | 归属阶段 |
|---|---|---|---|---|
| **RQ1** | 标签结构如何影响 RUL 任务的预测难度与**零学习基准误差**？ | 改变标签结构（h 谱），比较基准误差的变化 | `const_one` / `const_mean` / `best_const` / `LI` | Stage 2 |
| **RQ2** | 深度学习模型能否**稳定超越**零学习基准？ | 同一测试集上比较模型 RMSE 与常数基准 RMSE | `G = 1 − RMSE_model/RMSE_baseline`，主用 `const_mean` | Stage 2 |
| **RQ3** | 学习增益是否依赖**训练工况与测试轴承**？ | 控制测试对象，改变训练数据来源 | `R_cross` 并列 `ΔRMSE`（配对） | Stage 3 |
| **RQ4** | 跨工况训练是否带来**稳定的额外**预测信息？ | 配对实验 + **训练量匹配** + 统计不确定性 | `R_cross` / `ΔRMSE` 的多折分布 + 训练量匹配臂 | Stage 3 |

**依赖链**：RQ1 → RQ2 → RQ3 → RQ4。RQ1、RQ2 是解释 RQ4 的**必要基础**，不得跳过。

> **注**：RQ4 的措辞纪律与 H4 相同——只问「是否有稳定的额外信息」，**不问「是否等效」**。

## 3. 研究假设 H1–H5（冻结）

> V2.0 §2.3 给出的提案，本文确认冻结。**冻结后不得因实验结果反向修改**；只能记「支持 / 不支持 / 无法判定」。

| 编号 | 假设 | 可证伪条件 | 主要终点 |
|---|---|---|---|
| **H1** | 平台比例 `h` 越高，零学习基准误差越低、任务越不可判别；模型相对基准的增益随 `h` **单调下降**，存在临界 `h*` | 增益与 `h` 无单调关系，或临界点跨折不稳定 | `G(h)` 曲线 + `LI(h)` |
| **H2** | 在**退化保真标签**（`h→0`，即 linear）下，深度模型能稳定超越**可部署**基准 `const_mean`；高 `h` 下不能 | 高 `h` 下模型稳定超越 `const_mean`，或 `h→0` 下不能 | `G` 相对 `const_mean` |
| **H3** | 学习增益依赖**训练工况与测试轴承**，跨对象异质性**大于** run-to-run 噪声 | 折间异质性 ≤ 噪声带 | 折间/轴承间离散度 vs 噪声带 |
| **H4** | 严格配对下，跨工况相对单工况**未发现显著系统性差异** | 多折符号一致且超出噪声带 | `R_cross` 中位数 + CI + 符号一致性 |
| **H5** | 单/跨工况差异中，**可归因于训练样本量**的部分大于**可归因于工况迁移**的部分（训练量匹配后差异显著缩小） | 训练量匹配后差异不缩小 | 匹配臂前后的 `R_cross` / `ΔRMSE` 差值 |

### 3.1 H4 的措辞纪律（**强制**）

**允许**的表述：

- 「未发现显著系统性差异」
- 「在当前协议下，跨工况与单工况的配对差异**未超出** run-to-run 噪声带」
- 「`R_cross` 的中位数约为 1.06，配对检验 p = 0.153」

**禁止**的表述（除非补做**等效性检验**并**事先设定有实际意义的等效界值**）：

- ❌「跨工况与单工况**等效**」
- ❌「跨工况与单工况**等价 / 不可区分 / 无差异**」
- ❌「跨工况训练**没有价值** / 无收益」
- ❌ 任何把「未拒绝零假设」改写成「证明零假设成立」的句子

> 依据：V2.0 §1.7 判定表 + §2.3 注；参考建议原文「必须区分『未发现显著差异』与『证明两种方法等效』」。

### 3.2 H1 的措辞纪律

- `h ≈ 0.60` 交叉点**只能**作为「**待复核现象**」（pending, to be re-examined），不得作为 headline，
  不得预先指定某 `h` 为交叉点，不得预设 `LI(h)`–增益关系为线性。
  依据：V2.0 §1.5 B3、C12。

## 4. 三层贡献结构（替换 IP1–IP5 平行叙述）

| 层次 | 表述 | 证据要求 | 当前证据状态 |
|---|---|---|---|
| **① 评价框架** | 标签结构 — 零学习基准 — 学习增益的**统一分析框架**（含解析基准与严格配对协议） | 定义严格、数学与代码一致、基准角色分列 | 有雏形（基线阶梯 + `LI` + `R_cross`），**待严格化**（Audit 1/2/6） |
| **② 实验发现** | 增益随**标签结构 / 训练工况 / 测试对象**系统变化 | 多标签 × 多模型，报不确定性与绝对差 | **待重跑**（现结果出自修复前代码） |
| **③ 跨工况结论** | 跨工况是否提供**额外预测信息**及其**适用条件与限制** | 配对 + 训练量匹配 + 多折统计 + 统计单位=轴承 | 五折已有（修复后），**待训练量匹配 + 多模型** |

**红线**（V2.0 §2.1）：

1. **不得**把「跨工况没有稳定增益」预先写成既定结论——当前结果只是待验证的初步证据；
2. **不得**把零学习基准或严格评价协议**本身**直接包装成重大创新——它们必须服务于回答一个此前未被充分
   解释的科学问题，并由系统实验形成新认识。

**贡献的表述方式**（V2.0 §6.1）：从「我提出一个更好的模型」改写为
「我重建了一套评价判据，并用它诚实判定了标签结构与跨工况迁移的**真实增益边界**」；
架构退为**实验载体**，判据与证据链成为主线。
