## 2. 措辞纪律冻结（**硬约束**）

### 2.1 H4

**只允许**：`未发现显著系统性差异`。
**禁止**：`等效` / `等价` / `不可区分` / `无差异`（除非补等效性检验 + 事先设定等效界值）。
**禁止**：把「未拒绝零假设」改写为「证明零假设成立」。

> 触发点自查：本文件之后凡出现 `H4` 的句子，逐个检查是否含「等效」二字或其同义替换。

### 2.2 H1

**只允许**：`h ≈ 0.60` 为「**待复核现象**（pending, to be re-examined）」。
**禁止**：把 `h ≈ 0.60` 预先指定为交叉点，或在重跑前将其写入 headline / 结论 / 摘要。

### 2.3 LI(h)

**只允许**名称：`标签结构指标`（label-structure index）。
**禁止**：宣称它测量「真实退化信息 / 可预测性 / 可学习性」。

### 2.4 best_const

**只允许**角色：测试集**事后诊断**（post-hoc diagnostic），度量常数预测的极限。
**禁止**：称其为可部署基准，或与 `const_mean` 混用为同一口径。

## 3. 顺序纪律冻结（**不可逆序**）

判断顺序**恒为**：

```
研究设计  →  实验结果  →  是否支持假设  →  是否形成贡献
```

由此推出的三条执行禁令：

- **B1**：不得因实验结果反向修改 H1–H5 / RQ / 贡献结构（要改只能新增「标注为事后」的说明）。
- **B2**：不得在审计（Stage 1）完成前启动正式实验（N12）。
- **B3**：不得用「改了指标/口径后好看」的方式处理阴性结果（N13）。
